Qt概述

概念

  • Qt是一个跨平台的C++图形用户界面（GUI）应用程序框架，在1991年由奇趣科技开发。1996年进入商业领域，是目前流行的Linux桌面环境KDE的基础。

  • 常见的GUI框架有Qt、GTK、JavaFx、MFC等，其区别如下：

    框架 语言支持 特点 跨平台性 支持的平台
    Qt C++, Python, JavaScript (Qt Quick) 跨平台性、丰富的类库、信号与槽机制、界面设计工具 是，支持多种主流操作系统 Windows, Linux, macOS, Android, iOS 等
    GTK C, C++, Python, 等 轻量级、Linux系统中广泛使用 是，主要用于Linux Linux, Windows, macOS
    wxWidgets C++, Python, Perl, Ruby, 等 跨平台、本地外观、易于使用 是，支持多种主流操作系统 Windows, Linux, macOS, Android
    JavaFX Java 富客户端应用、丰富的图形和媒体功能 是，基于Java平台 Windows, Linux, macOS, Android, iOS 等
    Electron HTML, CSS, JavaScript 基于Web技术、跨平台、桌面应用开发 是，基于Web技术 Windows, Linux, macOS
    Tkinter Python Python的标准GUI库、简单易用 是，基于Python Windows, Linux, macOS
    MFC C++ Windows平台的本地GUI框架，Microsoft Visual C++ 不是，主要用于Windows Windows

优点

  1. 跨平台，几乎支持所有的平台
  2. 接口简单，容易上手，学习QT框架对学习其他框架有参考意义
  3. 一定程度上简化了内存回收机制
  4. 开发效率高，能够快速地构建应用程序
  5. 有很好的社区氛围，市场份额在缓慢上升
  6. 可以进行嵌入式开发
